# С чего начать объяснение

Представьте читателя в момент открытия документа: он выбирает вариант, устраняет ошибку или ищет справку? Для выбора сравните варианты по одному и тому же признаку. Для ошибки начните с наблюдаемого симптома и безопасного следующего шага. В справке дайте короткое определение и один пример на вымышленных данных. Проверьте, что заголовки позволяют найти ответ, не читая весь документ.
