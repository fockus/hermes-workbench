# codex — Workbench companion

When a model rejects the PATH-resolved CLI as too old on macOS, check whether Codex.app ships a newer CLI under `Contents/Resources/codex-cli/bin/codex`. Invoke its absolute path in a bounded scratch edit/readback probe with the identical model, effort and sandbox. Do not change global PATH, install software or substitute models merely to recover a version mismatch.
