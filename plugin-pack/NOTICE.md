# Права и источники

`plugin-pack/install.py` и описание упаковки — слой Workbench. Его MIT не распространяется на `sources/` или `services/recall/`. Автор разрешил перенос собственного кода в Workbench; новой MIT-лицензии на эти девять плагинов и движок Recall нет. Исходные имена авторов сохранены. В `catalog.json` приведены исходный коммит и Git tree каждого собственного компонента. Это отдельно от SHA-256 поставляемых файлов (`files.sha256.json`). Личный профиль, Git-история, существующие модели и установленные зависимости не являются частью поставки.

- **CodeMode:** исходный Python SDK, nested-tool adapter, Monty integration, CLI и его синтетические eval-модули. В `requirements.lock` четыре Python-дистрибутива с pin и wheel hashes; `pydantic-monty`, `pydantic-monty-client`, `pydantic-monty-runtime` 1.6.0 (MIT), `typing-extensions` 4.16.0 (PSF-2.0). Собственный SDK не становится MIT автоматически. Контекст опционального патча Hermes относится к [лицензии Hermes](../LICENSES/Hermes-Agent.txt); сам патч автоматически не применяется.
- **Workflows:** MIT-notice `Copyright (c) 2026 tintinweb` в `sources/workflows/vendor/pi-subagents/LICENSE`. Заимствованные `runtime.js`, `worker-source.js`, `journal.js`, `meta.js` сверены с npm; `json-schema.js` и `package.json` — собственная связка. Заголовок `progress.js` называет его port из Claude Code. Этот файл **не перепубликовывается** в Git. Для личной установки он читается из опубликованного `@tintinweb/pi-subagents@0.23.0` по полному SHA-512 архива и SHA-256 файла **до** передачи полного плагина штатному сканеру Hermes. До отдельного выяснения происхождения не распространяйте собранное репо с этим файлом. Node, shell-скрипты npm и Claude при сборке не запускаются.
- **Memory Bank и LLM Wiki:** исходные MIT-notices сохранены в `base-overlays/*/LICENSE`. У MB исходный локальный HEAD и изменённые рабочие файлы разделены в `source_provenance`; у Wiki исходный коммит не предполагается доступным в публичном remote. Поставляются blobs, а не локальные ветки. К исходным изменениям MB относится также переносимая правка `rules/RULES.md`; перечень добавленных файлов проекций и режимов — в `skill-pack/recovery/sources.json`. Базовые публичные runtimes и их notices остаются зафиксированы в [workbench.lock.json](../workbench.lock.json).
- **18 внешних пакетов:** установка из первоисточника по commit и subdir, без перевыдачи под лицензию Workbench. `notices/` содержит тексты корневых лицензий по этим точным ревизиям. У `openviking` адаптер под MIT, а корневой LICENSE сервера — GNU AGPLv3; у `kanban-gantt` — GPLv3 (не предполагаем «или позднее»). Вложенный runtime `project-memory-bank` имеет собственный LICENSE, который остаётся в исходной директории. Лицензия и обязательства других входящих компонентов сохраняются; ссылка на upstream не отменяет их.
**Каналы плагинов** приведены в [`catalog.json`](catalog.json); собственное разрешение на публикацию и исключения для сторонних файлов — в [`sources/NOTICE.txt`](sources/NOTICE.txt). В Workbench не входит право переиздать сборку с произвольным внешним файлом, зависимости идут со своими условиями.

- **Recall:** сервис использует SQLite/FTS5, NumPy; опционально ONNX Runtime, tokenizers и веса. Версии прямых пакетов, найденные в исходной среде, перечислены отдельно. Они не являются лицензией моделей или lock-файлом всех транзитивных пакетов. Не упакованы персональные plist/адреса, БД, embeddings, файлы модели, документы или поисковые индексы.
