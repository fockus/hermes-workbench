# Проверка инкремента внешних CLI

Основание публичного preview Workbench: `d8f6a7ec28a0e5fdd85ede1f679d9f07ee7367e5`. Основание Hermes: `v0.23.3`, `caafe5389ae585ef77387a962aee05b1bcf17029`. У базового Workbench не изменены `workbench.lock.json`, launchers, патчи, лицензии и состав двух штатных плагинов. Новый плагин включается только с `--with-executors`; его байты закреплены отдельно. Проверка на macOS arm64.

| Проверка | Наблюдаемый результат |
|---|---|
| Тесты до реализации | База 9/9. Пять новых красных тестов: флаг установки и плагин отсутствовали. Позже отдельные красные проверки поймали несовместимость OpenCode и отсутствие запроса подтверждения. |
| Регрессии | Итоговые 17/17 unit-тестов. В том числе отдельный процесс на каждый CLI, буквальный ввод с shell-метасимволами, свежий cwd, неунаследованное окружение, отказ чтения/записи внешнего файла, отсутствие бинарника, неверная версия или маршрут, отсутствие согласия, ненулевой exit, timeout, превышение объёма и запрет соединения с другим слушающим loopback-портом. `ruff check .`, ShellCheck обоих launcher и `git diff --check` прошли. |
| Новая установка | `--with-executors --with-tui --source <pinned checkout>` завершилась в новом prefix. Реальный Hermes зарегистрировал команду, в `plugins.enabled` три плагина. Graphite активен, 56/56 целевых UI-тестов прошли. Штатный smoke `/mb` и `llm_wiki_status/search/read/graph` прошёл на свежих банках. Пользовательских документов в Wiki нет. |
| Повтор | Повтор и `--check` с теми же флагами сверили артефакты. Хеши `config.yaml`, синтетического `routes.json` и receipt не изменились. Без `--with-executors` повтор отказал из-за несовпадающего режима. После проверки тестовые маршруты и привязки удалены. |

**Настоящие процессы и синтетическая модель.** Для каждого CLI нативная top-level команда Hermes вызвала `--version` и help. Затем `invoke_plugin_command` нашёл зарегистрированный `/executor`; `ask_choice` получил положительный ответ **только от тестового выбора для синтетической метки**. Реальный CLI отправил метку на одноразовый HTTP/SSE-стенд, а диспетчер Hermes вернул отдельную случайную строку из ответа. Для всех четырёх также проверен отказ top-level команды без терминального подтверждения.

| CLI | Версия | Путь, на котором стенд получил метку и вернул результат |
|---|---|---|
| Codex CLI | `codex-cli 0.170.0` | `/v1/responses` |
| Pi | `1.5.0` | `/v1/chat/completions` |
| OpenCode | `opencode v2.0.18` | `/v1/chat/completions` (два запроса); приватный `serve --stdio` и клиент `run --server` |
| Claude Code | `2.1.327 (Claude Code)` | `/v1/messages?beta=true` |

Не проверялись платная inference, личная авторизация или настоящий удалённый провайдер. Тест не доказывает качество модели и не имитирует нажатия человеком в настоящем UI. Команды воспроизведения и границы доверия: [EXECUTORS.md](EXECUTORS.md). Для базового выпуска сохранён отдельный [исторический отчёт](VERIFICATION.md).
